# Pangasinan Heritage Digital Showcase

## Student Name
Denver Cadag

## Selected Framework
Vue.js + Nuxt.js

## Project Description
The Pangasinan Heritage Digital Showcase is a responsive tourism website that highlights selected heritage and tourist destinations in Pangasinan.

Featured sites include:
- Hundred Islands
- Bolinao Lighthouse
- Balungao Hot Spring
